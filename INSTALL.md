# Установка VoiceSwitch

## Готовый beta-релиз

1. Скачайте arm64 ZIP из раздела
   [GitHub Releases](https://github.com/mitimaicode/VoiceSwitch/releases).
2. Сверьте SHA-256 при необходимости:

   ```zsh
   shasum -a 256 VoiceSwitch-*.zip
   ```

3. Распакуйте архив и перенесите `VoiceSwitch.app` в `/Applications`.
4. Поскольку beta пока не нотарифицирована Apple, щёлкните приложение правой
   кнопкой, выберите **Открыть** и подтвердите запуск.
5. В меню VoiceSwitch нажмите **Установить модели**.

Установщик загружает закреплённую версию `uv`, изолированный Python 3.12,
Python-зависимости, ffmpeg и веса двух моделей. Администраторский пароль не
требуется; системный Python и shell-профиль не изменяются.

## Разрешения macOS

VoiceSwitch просит только разрешения, необходимые для работы:

- **Микрофон** — запись речи;
- **Универсальный доступ** — глобальная горячая клавиша и вставка текста в
  активное приложение.

Если текст распознаётся, но не вставляется:

1. откройте **Системные настройки → Конфиденциальность и безопасность →
   Универсальный доступ**;
2. включите VoiceSwitch;
3. полностью завершите и снова запустите приложение.

Без универсального доступа распознанный текст копируется в буфер обмена.

## Файлы и удаление

Приложение:

```text
/Applications/VoiceSwitch.app
```

Модели, Python и журнал:

```text
~/Library/Application Support/VoiceSwitch
```

Чтобы полностью удалить VoiceSwitch, удалите приложение и эту папку. Записи
речи не архивируются: временный WAV удаляется после распознавания.

## Известные ограничения beta

- только Apple Silicon и macOS 14+;
- первая установка занимает несколько гигабайт и может быть долгой;
- приложение пока не подписано сертификатом Apple Developer ID;
- автоматическое обновление ещё не реализовано.

При проблеме создайте
[Issue](https://github.com/mitimaicode/VoiceSwitch/issues/new/choose) и приложите
версию macOS, модель Mac, выбранный движок и текст ошибки. Не публикуйте
приватные расшифровки или журнал целиком.
