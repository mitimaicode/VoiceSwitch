# VoiceSwitch v0.3.2-beta

Исправление установки GigaAM для новых пользователей и существующих установок.

## Что исправлено

- В окружение явно добавлена обязательная зависимость `torchaudio`, без которой GigaAM завершался ошибкой `ModuleNotFoundError`.
- Перед загрузкой модели установщик проверяет импорт `torch`, `torchaudio` и `gigaam` и показывает понятную ошибку восстановления окружения.
- Повтор этапа больше не называется исключительно сетевой ошибкой: повтор может потребоваться и после сбоя установки пакетов.
- Версия Runtime повышена до 4, поэтому приложение автоматически дополнит существующее окружение недостающей зависимостью.

## Как обновиться

Замените приложение новой версией и нажмите **«Продолжить установку»**. Уже загруженные модели и кэш сохраняются; удалять папку Runtime не требуется.
