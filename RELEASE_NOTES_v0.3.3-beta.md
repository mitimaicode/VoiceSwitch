# VoiceSwitch v0.3.3-beta

Более простая установка без платной подписи Apple.

## Что изменилось

- Добавлен мастер первого запуска: выбор моделей, разрешения macOS и проверка готовности.
- GigaAM стал рекомендуемым стартовым комплектом вместо обязательной загрузки всех моделей.
- Whisper, Qwen3-ASR и редактор Qwen3-4B устанавливаются независимо и только по требованию.
- Текущая полная установка Runtime v4 распознаётся автоматически и не требует повторной загрузки моделей.
- Release-скрипт создаёт DMG с ярлыком «Программы» и короткой инструкцией первого запуска.
- GitHub Release публикует DMG, ZIP и контрольные суммы обоих файлов.
- Исправлена автоматическая вставка в Codex, Electron и WebView: VoiceSwitch
  проверяет фактически активное приложение и использует надёжный резервный
  `Command + V`, если поле сообщает ложный успех Accessibility.
- В журнал добавлена диагностика доставки текста: разрешение универсального
  доступа, приложение-получатель и выбранный способ вставки.

## Первый запуск

1. Откройте DMG и перенесите VoiceSwitch в «Программы».
2. Нажмите приложение правой кнопкой и выберите «Открыть».
3. В мастере выберите «Русская диктовка».
4. Разрешите микрофон и универсальный доступ.

Если после обновления речь распознаётся, но текст только копируется в буфер,
выключите и снова включите VoiceSwitch в разделе **Системные настройки →
Конфиденциальность и безопасность → Универсальный доступ**, затем полностью
перезапустите приложение. Публичная beta использует бесплатную ad-hoc подпись,
поэтому macOS иногда требует повторное разрешение после замены приложения.

Модели и настройки сохраняются в `~/Library/Application Support/VoiceSwitch`,
поэтому при обновлении приложения повторная загрузка не требуется.
