# Security Policy

Поддерживаемая ветка: последняя опубликованная beta-версия.

Не публикуйте уязвимость, секреты, приватные записи или расшифровки в обычном
Issue. Используйте приватную форму **Security → Report a vulnerability** в
репозитории GitHub. Если private vulnerability reporting недоступен, создайте
Issue без технических подробностей с просьбой связаться с вами.

Укажите версию VoiceSwitch, macOS, модель Mac, ожидаемое и фактическое
поведение. Мы постараемся подтвердить получение сообщения в течение семи дней.
