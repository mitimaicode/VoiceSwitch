# Участие в разработке

Спасибо за интерес к VoiceSwitch.

## Куда писать

- Ошибка, которую можно воспроизвести, — GitHub Issue.
- Вопрос по установке или использованию — GitHub Discussions.
- Идея без готовой реализации — Discussions → Ideas.
- Исправление кода — Pull Request.

Перед созданием Issue проверьте существующие обращения и убедитесь, что
проблема воспроизводится на последнем релизе.

## Локальная проверка

```zsh
swift build
zsh -n scripts/*.sh Resources/install_runtime.sh
python3 -m py_compile worker/asr_worker.py scripts/collect_github_stats.py
```

Для изменения распознавания желательно приложить обезличенный набор тестовых
фраз и результаты затронутых моделей. Не добавляйте в репозиторий аудиозаписи,
веса моделей, Runtime, журналы или персональные расшифровки.

Отправляя Pull Request, вы соглашаетесь распространять вклад по лицензии MIT.
